## 10. 검토 질문에 대한 답변

#### 질문 1: DSL 쿼리 입력 방식
**선택한 옵션:** JSON 텍스트 에디터 (기본 TextField + JSON 파싱 검증)
**선택 이유:** OpenSearch DSL은 복잡하므로 자유로운 입력이 필요함.

#### 질문 2: 채널 설정 UI
**선택한 옵션:** 섹션별 추가 버튼 및 목록 형태
**선택 이유:** 사용자가 여러 채널을 유연하게 설정할 수 있어야 함.
