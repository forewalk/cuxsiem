# 알림 규칙 관리 (Notification Rule Management) 구현 보고서

## 🏗 구현 결과 요약
알림 규칙의 생성, 수정, 삭제 및 상태 관리를 위한 전체 인터페이스와 백엔드 API 연동을 완료하였습니다.

### 1. 주요 구현 항목
- **규칙 목록 UI (`NotificationRuleListTab.tsx`)**:
    - MUI `DataGrid`를 활용한 규칙 목록 표시.
    - 검색 및 필터링 기능 통합.
    - 활성화/비활성화 즉시 토글 기능.
- **규칙 설정 폼 (Dialog)**:
    - 탐지 조건(DSL 쿼리) 입력을 위한 JSON 에디터 스타일의 텍스트 영역.
    - 실행 주기(`interval_min`) 및 탐지 범위(`window_min`) 설정 및 유효성 검사.
    - 수신 대상(Receiver) 정의 기능.
- **발송 채널 관리**:
    - Webhook, Slack, Email 채널을 동적으로 추가/삭제할 수 있는 UI 구현.
- **백엔드 CRUD**:
    - OpenSearch `cs_notification_rules` 인덱스를 활용한 영속성 계층 구축.

### 2. 기술적 특징
- **중첩 객체 상태 관리**: 복잡한 `channels` 객체 구조를 React 상태로 안정적으로 관리하기 위한 불변성 업데이트 로직 적용.
- **i18n 통합**: 한국어, 영어, 일본어 환경에서 모든 라벨 및 메시지가 정상 출력되도록 `locales/*.json` 연동.
