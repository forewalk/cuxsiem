# 로그 스트리밍 기능 기획서

## 1. 개요
오픈서치(OpenSearch) 인덱스에 저장된 로그 데이터를 실시간으로 조회하여 웹 인터페이스에 스트리밍하는 기능입니다. 보안 관제 요원이 최신 보안 이벤트를 즉각적으로 모니터링할 수 있도록 10초 주기로 데이터를 자동 갱신합니다.

## 2. 사용자 시나리오
1. 사용자는 로그인 후 대시보드 메뉴 하위의 "로그 스트리밍" 메뉴를 클릭합니다.
2. 화면에는 터미널 또는 콘솔 스타일의 로그 뷰어가 표시됩니다.
3. 뷰어는 자동으로 가장 최근 로그를 하단에 추가하며 스크롤됩니다.
4. 각 로그 라인은 `타임스탬프`, `인덱스명`, `메시지`로 구성됩니다.

## 3. 기능 요구사항

### 3.1 프론트엔드
- **메뉴 구성:**
  - 사이드바의 "대시보드" 하위 메뉴로 "로그 스트리밍" 추가.
- **UI 디자인:**
  - `docs/figma/reallog.svg` (어두운 배경의 콘솔 스타일 지향) 디자인 참조.
  - 가독성을 높이기 위해 고정폭 폰트(Monospace) 사용.
  - 새 로그가 추가되면 자동으로 화면 최하단으로 스크롤 (Auto-scroll).
  - 스트리밍 중지/재개 버튼 (선택 사항, 추후 고도화).
- **데이터 표시:**
  - 표시 항목: `timestamp`, `_source`.
  - 날짜 형식: `YYYY-MM-DD HH:mm:ss` 포맷팅.

### 3.2 백엔드
- **API 엔드포인트:**
  - `GET /api/v1/logs/stream`: 최신 로그 조회.
  - 파라미터: `last_timestamp` (마지막으로 조회한 로그 시간, 이후 데이터만 조회용) 또는 `limit` (초기 로딩용).
- **데이터 소스:**
  - OpenSearch에 저장된 모든 인덱스.
  - 쿼리: `timestamp` 기준 내림차순 정렬하여 최신 N개 조회.

### 3.3 보안 및 권한
- 로그인한 사용자만 접근 가능 (JWT 인증).

## 4. 기술 스택
- **Frontend:** React, Material UI (MUI), Axios
- **Backend:** FastAPI, opensearch-py
- **Database:** OpenSearch

## 5. 데이터 흐름
1. **초기 로드:** 페이지 진입 시 최근 50개 로그 로드.
2. **폴링 (Polling):** `setInterval`을 사용하여 10초마다 API 호출.
3. **업데이트:** 마지막으로 받은 로그의 `timestamp` 이후 데이터만 요청하여 리스트 뒤에 추가.
