## ✅ 확정된 개발 계획

### 목표
OpenSearch의 `activities` 인덱스에서 실시간 로그 데이터를 조회하여 웹 인터페이스에 스트리밍하는 기능을 구현합니다. 보안 관제 요원이 최신 이벤트를 10초 주기로 모니터링할 수 있도록 합니다.

### 개발 범위 (확정)
- **Backend:** `GET /api/v1/logs/stream` 엔드포인트 및 OpenSearch 연동
- **Frontend:** 로그 스트리밍 뷰어 컴포넌트, 서비스 레이어, 타입 정의, 메뉴 통합

## 2. API 설계 (확정)
### GET /api/v1/logs/stream
- **Query Params:**
  - `last_timestamp` (string, optional): 이 시간 이후의 로그만 조회
  - `limit` (int, default=100): 조회 개수 제한
- **Response Body:**
  ```json
  {
    "logs": [
      {
        "_id": "...",
        "_index": "...",
        "timestamp": "...",
        "message": "...",
        "_source": { ... }
      }
    ],
    "last_timestamp": "..."
  }
  ```
