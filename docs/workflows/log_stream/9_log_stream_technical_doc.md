# 로그 스트리밍 기능 기술 문서

## 1. 개요
이 문서는 OpenSearch의 `activities` 인덱스 데이터를 실시간으로 모니터링하기 위한 로그 스트리밍 기능의 기술적 구현 명세를 설명합니다.

## 2. 아키텍처

### 2.1 백엔드 (FastAPI)
- **Endpoint:** `GET /api/v1/logs/stream`
- **구현 로직:**
  - OpenSearch 클라이언트를 통해 `timestamp` 기준 내림차순 정렬 조회를 수행합니다.
  - `last_timestamp` 파라미터를 사용하여 이전 호출 이후에 생성된 새로운 로그만 필터링하여 가져옵니다.
  - 결과 리스트를 다시 오름차순으로 정렬하여 프론트엔드에 전달함으로써 최신 로그가 아래에 위치하도록 합니다.

### 2.2 프론트엔드 (React + MUI)
- **컴포넌트:** `LogStreamingTab`
- **상태 관리:**
  - `logs`: 현재 화면에 표시 중인 로그 배열 (최대 1,000개).
  - `isPaused`: 폴링 일시 정지 여부.
  - `autoScroll`: 새 로그 유입 시 최하단 이동 여부.
- **주요 로직:**
  - `setInterval`을 이용해 10초마다 백엔드 API를 호출합니다.
  - `useRef`를 사용하여 마지막 수신 로그의 타임스탬프를 추적합니다.
  - 중복 수신 방지를 위해 로그의 `_id` 필드를 대조하여 필터링합니다.

## 3. UI/UX 디자인
- **테마:** 다크 모드 기반의 터미널 스타일 배경 (#1e1e1e).
- **폰트:** Monospace 계열을 사용하여 로그 가독성을 확보했습니다.
- **자동 스크롤:** 사용자가 현재 위치를 유지하고자 할 때(위로 스크롤 시) 자동 스크롤을 감지하여 해제하는 스마트 스크롤 기능을 포함합니다.

## 4. 설정 및 환경변수
- OpenSearch 연결 정보는 백엔드 `.env` 설정을 따릅니다.
- 프론트엔드 폴링 주기는 `POLL_INTERVAL` 상수로 조절 가능합니다. (기본 10,000ms)
