# 기획서: 로그 스트리밍 기능 강화 (필드 선택 및 필터링)

## 1. 개요
로그 스트리밍 화면(`LogStreamingTab`)에서 사용자가 보고 싶은 데이터를 자유롭게 선택하고, 상세 정보에서 즉시 필터링 조건을 추가할 수 있도록 개선합니다.

## 2. 주요 기능
### 2.1 필드 선택기 (Field Selector)
- 로그 목록에서 표시할 컬럼(필드)을 동적으로 선택할 수 있는 UI 제공.
- 현재 수집된 로그들의 `_source`에서 사용 가능한 필드 목록을 자동으로 추출.
- 기본 필드(`timestamp`, `_index`, `message`)는 고정하거나 우선순위 부여.
- 필드 선택 시 실시간으로 로그 테이블의 컬럼이 업데이트됨.

### 2.2 상세 패널 필터링 (Filter from Detail)
- `LogDetailPanel`에서 특정 필드나 값을 클릭하면 검색창(`searchQuery`)에 해당 조건 추가.
- 예: `category: "auth"` 필드를 클릭하면 검색창에 `AND category: "auth"` 추가.
- 이미 조건이 있는 경우 논리적으로 결합.

## 3. 기술적 변경 사항
- **State 관리**: `visibleFields`를 상위 컴포넌트에서 관리하고 사용자가 변경할 수 있도록 수정.
- **UI/UX**: 
  - 컨트롤바 부근에 '필드 설정' 버튼(Popover/Menu) 추가.
  - 상세 패널의 각 행에 '필터 추가(+)' 버튼 또는 클릭 이벤트 추가.
- **데이터 처리**: 로그 데이터에서 중복 없는 필드 목록(Flat keys) 추출 로직 구현.

## 4. 기대 효과
- 사용자가 불필요한 필드를 숨기고 중요한 데이터에 집중할 수 있음.
- 타이핑 없이 마우스 클릭만으로 복잡한 필터 조건을 빠르게 생성 가능.
