# 확정된 기획서: 로그 스트리밍 기능 강화

## 1. 구현 목표
- 로그 스트리밍 화면의 데이터 탐색 편의성 극대화.
- 사용자가 직접 컬럼을 구성하고 마우스 클릭만으로 필터링을 수행하는 인터페이스 구축.

## 2. 상세 구현 사양
### 2.1 필드 선택기 (Field Selector)
- **위치**: 컨트롤바 우측, 'Paused/Streaming' 버튼 왼쪽에 배치.
- **기능**:
  - 버튼 클릭 시 현재 `logs`에서 추출된 고유 필드 목록 표시.
  - 체크박스를 통해 표시/숨김 토글.
  - `timestamp`는 필수 필드로 고정(해제 불가).
- **데이터 로직**: `useMemo`를 사용하여 `logs`가 업데이트될 때마다 사용 가능한 필드 목록 최신화.

### 2.2 상세 패널 필터링 (Filter from Detail)
- **위치**: `LogDetailPanel`의 각 행(Row).
- **기능**:
  - 행에 마우스를 올리면 '필터에 추가' 아이콘 표시 또는 키/값 클릭 시 작동.
  - 클릭 시 `searchQuery`에 `field: "value"` 형식으로 추가.
  - 이미 검색어가 있다면 ` AND `로 결합.

## 3. 작업 범위
- `LogStreamingTab.tsx` 파일 수정.
- `LogDetailPanel` 컴포넌트에 `onFilterAdd` 콜백 추가.
- `FieldSelector` UI용 컴포넌트(내부 또는 별도 분리) 추가.

## 4. 제약 사항
- 브라우저 로컬 스토리지 저장은 이번 단계에서 제외 (세션 유지).
- 복합 쿼리(`OR`, `NOT`) 빌더는 제외하고 단순 `AND` 결합만 지원.
