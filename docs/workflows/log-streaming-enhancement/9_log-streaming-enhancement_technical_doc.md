# 기술 문서: 로그 스트리밍 기능 강화

## 1. 개요
로그 스트리밍 화면의 사용 편의성을 높이기 위해 필드 동적 선택 기능과 상세 패널을 통한 즉시 필터링 기능을 구현하였습니다.

## 2. 변경 사항

### 2.1 필드 선택 (Field Selector)
- **컴포넌트**: `FieldSelectorPopover`
- **로직**:
  - 최근 수집된 100개의 로그로부터 가용한 모든 필드를 추출합니다.
  - 사용자는 체크박스를 통해 목록에 표시할 필드를 선택할 수 있습니다.
  - `timestamp` 필드는 필수 필드로 고정되어 있습니다.
- **UI**: 툴바에 '필드' 버튼을 추가하여 접근성을 높였습니다.

### 2.2 상세 필터링 (Filter from Detail)
- **컴포넌트**: `LogDetailPanel`
- **로직**:
  - 상세 패널의 각 행(Row)을 클릭하거나 필터 아이콘을 클릭하면 해당 필드와 값 조건이 검색창에 자동으로 추가됩니다.
  - 기존 검색어가 있는 경우 `AND` 조건으로 결합됩니다.
- **UI**: 행에 마우스를 올릴 때 필터 추가 아이콘을 표시하여 인터랙션을 유도합니다.

## 3. 사용 방법
1. **필드 변경**: 상단 툴바의 [필드] 버튼을 눌러 원하는 컬럼을 선택하거나 해제합니다.
2. **필터 추가**: 로그 상세 패널을 열고, 필터링하고 싶은 값의 행을 클릭합니다. 상단 검색창에 쿼리가 자동으로 완성되며 목록이 갱신됩니다.

## 4. 향후 과제
- 선택된 필드 설정을 브라우저의 `localStorage`에 저장하여 유지하는 기능 검토.
- `OR`나 `NOT` 조건을 지원하는 고급 쿼리 빌더 인터페이스 확장 가능성.
