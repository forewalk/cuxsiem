# 확정 기획서: admin

## 1. 개요
- **목적**: 시스템 관리자가 사용자 및 보안 정책을 관리할 수 있는 중앙화된 관리 페이지 구축.
- **범위**: 사이드바 개편, 탭 시스템 도입, 사용자 관리 UI, 패스워드 정책 UI.

## 2. 요구사항 확정

### 2.1 사이드바 (AdminSidemenu)
- 접힘/펼침 토글 지원.
- '관리자 메뉴'는 최하단 고정.
- 2단계 계층 구조: 관리자 메뉴 > (사용자 관리, 패스워드 정책).
- `admin` 권한 체크 필수.

### 2.2 탭 관리 시스템 (TabManager)
- Zustand 스토어(`useTabStore`)에서 관리.
- 최대 탭 개수: 5개.
- 탭 전환 시 컴포넌트 언마운트 방지 또는 상태 보존 로직 적용.
- 탭 닫기(X) 기능 지원.

### 2.3 사용자 관리
- 데이터 그리드 표시 (이름, 이메일, 역할, 상태, 생성일, 마지막 로그인).
- 생성/수정/삭제 기능.
- **본인 및 타 관리자 삭제 불가** 조건 추가.

### 2.4 패스워드 정책
- 설정 항목: 최소 길이, 복잡성(대/소문자/숫자/특문), 재사용 제한(이력), 잠금 정책.

## 3. 화면 설계
- 헤더: 기존 유지 (로그인 정보, 언어, 테마).
- 본문: `TabManager`가 상단에 위치하고 하단에 콘텐츠 영역 배치.
