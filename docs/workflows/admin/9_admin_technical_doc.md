# 기술 문서: admin

## 1. 아키텍처 개요
관리자 시스템은 Zustand 기반의 탭 관리 시스템과 계층형 사이드바 메뉴로 구성됩니다.

## 2. 주요 구성 요소

### 2.1 상태 관리 (`tabStore.ts`)
- `tabs`: 열려 있는 탭의 배열 (`label`, `component`, `props` 포함).
- `activeTabId`: 현재 활성화된 탭의 ID.
- `MAX_TABS`: 5개로 제한.

### 2.2 UI 구성 요소
- **AdminSidemenu**: 2단계 메뉴 구조를 지원하며, 관리자 메뉴는 하단에 위치합니다. 하위 메뉴 클릭 시 탭이 생성됩니다.
- **TabManager**: MUI `Tabs`를 사용하여 탭 인터페이스를 제공하며, `display: none`을 활용하여 탭 전환 시에도 컴포넌트의 상태를 보존합니다.
- **AdminPage**: 탭 시스템의 메인 컨테이너입니다.

## 3. 구현 세부 사항
- **사용자 관리**: DataGrid를 사용하며, 역할이 `admin`인 사용자는 삭제 버튼이 비활성화됩니다.
- **패스워드 정책**: 복잡성 규칙 및 보안 설정을 OpenSearch와 연동하여 관리합니다.

## 4. 보안
- `AdminRoute` 컴포넌트를 통해 인증되지 않았거나 관리자 권한이 없는 사용자의 접근을 차단합니다.
- 백엔드 API 또한 `current_admin` 의존성을 통해 권한을 검증합니다.
