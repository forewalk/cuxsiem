# 기능 기획서: admin

- 날짜: 2026-02-01
- 작성자: Gemini
- 상태: 초안

## 1. 개요
관리자 전용 페이지를 구축하여 사용자 계정 및 시스템 정책(패스워드 등)을 관리할 수 있는 기능을 제공합니다.

## 2. 요구사항 (사용자 요청 기반)

### 2.1 UI/UX 구조
- **사이드바 메뉴**:
  - 접힘/펼침 가능.
  - 2단계 구조.
  - **대시보드**: 1단계 메뉴.
  - **관리자 메뉴**: 1단계 최하단 위치. `admin` 권한 소유자에게만 표시.
  - **하위 메뉴**: '관리자 메뉴' 클릭 시 '사용자 관리', '패스워드 정책' 표시.
  - **활성화 표시**: 선택된 메뉴는 색상 변경 등으로 강조.
- **메인 콘텐츠**:
  - 탭(Tab) 기반 시스템.
  - 최대 5개 탭까지 오픈 가능 (초과 시 알림 메시지).
  - 탭 전환 시에도 작성 중인 상태나 설정값이 유지되어야 함.
  - 사이드바 접힘 시 메인 영역 확장.
- **헤더**:
  - 오른쪽: 다크모드 토글, i18n 언어 설정.
  - 왼쪽: 로그인 사용자 이름, 권한, 로그아웃 버튼.

### 2.2 상세 기능
- **사용자 관리 (User Management)**:
  - OpenSearch API를 통해 사용자 목록 조회.
  - 사용자 추가, 수정 기능.
  - **제한 사항**: 관리자(Admin) 계정 자체는 삭제하지 못하도록 제한.
- **패스워드 정책 (Password Policy)**:
  - 패스워드 최소/최대 자리수 설정.
  - 영문, 숫자, 특수문자 조합 필수 여부 설정.
  - 이전 패스워드 기억(재사용 제한) 여부 설정.
  - 계정 잠금 임계치 및 기간 설정.
