# 알림 센터 (Notification Center) 기능 명세서

## 1. 개요
관리자 설정 메뉴 하위에 알림 관련 기능을 통합 관리할 수 있는 '알림 센터' 메뉴를 추가한다.

## 2. 요구사항
- **대상:** 관리자(admin) 계정
- **위치:** 사이드바의 '관리 설정' 메뉴 하위
- **구조:**
    - 관리 설정
        - 사용자 관리
        - 비밀번호 정책
        - **알림 센터 (아코디언/Collapse 형태)**
            - **알림 규칙 목록**
            - **알림 내역**
- **동작:**
    - '알림 센터' 클릭 시 하위 메뉴(알림 규칙 목록, 알림 내역)가 펼쳐지거나 접혀야 함 (Collapse).
    - '알림 규칙 목록' 및 '알림 내역' 클릭 시 해당 페이지로 네비게이션 및 탭 추가.
    - 다국어 지원 (ko, en, ja).

## 3. 상세 기능
### 3.1 사이드바 메뉴 업데이트
- `AdminSidemenu.tsx` 수정
- '알림 센터' 아이콘: `Notifications` 아이콘 사용.
- '알림 규칙 목록' 아이콘: `ListAlt` 아이콘 사용.
- '알림 내역' 아이콘: `History` 아이콘 사용.

### 3.2 다국어 키 추가
- `ko.json`, `en.json`, `ja.json`에 다음 키 추가:
    - `notificationCenter`: 알림 센터
    - `notificationRuleList`: 알림 규칙 목록
    - `notificationHistory`: 알림 내역

## 4. 논의 사항
- 현재 페이지가 구현되어 있지 않으므로, 클릭 시 기존 탭 시스템(`useTabStore`)을 통해 '구현 중'임을 알리거나 빈 탭을 생성하는 방식으로 처리.
