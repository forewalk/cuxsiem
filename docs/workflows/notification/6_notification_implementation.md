# 알림 감지 및 전송 (Notification Detection & Delivery) 구현 보고서

## 🏗 구현 결과 요약
백그라운드 탐지 엔진, 실시간 알림 내역 모니터링, 그리고 발송 증적(Evidence) 시스템을 포함한 알림 센터의 핵심 기능을 완료하였습니다.

### 1. 주요 구현 항목
- **백그라운드 탐지 엔진**:
    - `APScheduler`를 이용한 1분 주기 자동 탐지 프로세스 구축.
    - OpenSearch `@timestamp` 필드를 이용한 실시간 데이터 매칭.
- **알림 내역 모니터링 (`NotificationHistoryTab.tsx`)**:
    - 10초 주기의 자동 데이터 폴링(Polling) 시스템.
    - **인라인 확장 UI**: 행 클릭 시 부드럽게 펼쳐지는 상세 정보창 (MUI Table + Collapse).
- **발송 증적(Evidence) 시스템**:
    - "무엇을 보냈는가"를 증명하기 위한 상세 로그 기록 (`outgoing_payload`, `endpoint`, `status_code` 등).
    - **Dual View**: 상세창 내에서 좌측은 텍스트 정보, 우측은 가공된 JSON 페이로드를 표시.
- **실시간 사용자 알림**:
    - 신규 알림 발견 시 우측 하단에 3초간 노출되는 Snackbar(Alert) 구현.

### 2. 기술적 특징
- **Master-Detail 패턴**: `DataGrid`의 한계를 넘어선 커스텀 테이블 구현을 통해 피그마 시안의 고도화된 상세 뷰 재현.
- **보안 마스킹**: 증적 로그 저장 시 API Key 등 민감한 헤더 정보를 자동으로 마스킹 처리.
- **추적성(Traceability)**: 알림 내역과 원본 이벤트를 `event_ref`를 통해 연결.

### 3. 미흡 사항 및 향후 과제
