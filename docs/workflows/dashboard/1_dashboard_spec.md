## 1. 개요

### 1.1 목적
SIEM 시스템의 핵심 정보를 한눈에 파악할 수 있는 시각화 대시보드 구현.

### 1.2 배경
사용자가 수집된 로그 현황, 보안 위협 스코어, 시스템 상태 등을 직관적으로 모니터링할 수 있는 공간이 필요함.

### 1.3 범위
**포함:**
- 상단 컨트롤 바 (기간 선택, 필터, 새로고침 등)
- 통계 차트 (Bar Chart 등 시각화 위젯)
- 데이터 그리드 (로그 리스트 또는 요약 정보)
- MUI 기반의 반응형 레이아웃

**제외:**
- 커스텀 위젯 편집기 (Phase 2 이후 고려)
- 외부 시스템 임베딩

---

## 2. 요구사항

### 2.1 기능 요구사항
1. **기간 선택:** 특정 기간(15분, 1시간, 24시간 등)의 데이터를 필터링하는 기능
2. **시각화 위젯:** OpenSearch 데이터를 기반으로 한 막대 차트(Bar Chart) 표시
3. **자동 갱신:** 설정된 주기마다 데이터를 자동으로 불러오는 기능
4. **반응형 그리드:** 해상도에 따라 위젯 배치가 유연하게 조절되는 레이아웃
