# [최종개발계획] 계정 신청 기능 (Account Application)

## 1. 개요
2026-02-10에 확정된 기획서 및 개발 계획에 따라 구현을 진행함.

## 2. 최종 확정된 작업 범위
- **백엔드**: `auth` 라우터에 `/apply` 엔드포인트 추가 및 `is_active=false`, `role=user` 강제 로직 적용.
- **프론트엔드**: 로그인 페이지 연동, `AccountApplyModal` 구현, 실시간 비밀번호 정책 검증.
- **공통**: 다국어 처리(KO, EN, JA).

## 3. 일정 및 우선순위
1. 백엔드 API 및 스키마 구현 (최우선)
2. 프론트엔드 서비스 및 다국어 설정
3. 프론트엔드 UI(모달 및 로그인 페이지) 구현

## 4. 특이사항
- 비밀번호 정책 검증은 기존 `password_policy` API를 활용하여 프론트엔드에서 처리함.
- 디자인은 제공된 `a1.png`를 충실히 따르되, 불필요한 필드는 제거함.

## 5. 승인 완료
