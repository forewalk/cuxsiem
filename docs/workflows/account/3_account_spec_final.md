# [최종기획서] 계정 신청 기능 (Account Application)

## 1. 확정된 개요
로그인 페이지에서 일반 사용자가 계정 생성을 신청할 수 있는 기능을 제공한다. 신청된 계정은 보안상 '비활성화' 상태로 생성되며, 관리자의 승인 후에만 시스템 이용이 가능하다.

## 2. 확정된 기능 요구사항
1.  **진입점**: 로그인 페이지(`Login.tsx`) 하단에 '계정 신청' 링크 추가.
2.  **신청 폼**: `a1.png` 디자인을 기반으로 한 모달 다이얼로그.
    - 입력 필드: 아이디, 이메일, 이름, 비밀번호, 비밀번호 확인.
    - 제외 필드: 역할(Role), 상태(Status) - UI에서 제거.
3.  **데이터 규칙**:
    - `role`: 'user' 고정 (백엔드 강제)
    - `is_active`: `false` 고정 (백엔드 강제)
4.  **비밀번호 정책 연동**:
    - `passwordPolicyService`를 통해 정책을 로드하고 실시간으로 검증 UI 제공.
5.  **성공 처리**: 신청 완료 후 "계정 신청이 완료되었습니다. 관리자 승인 후 이용 가능합니다." 메시지 출력 및 모달 닫기.

## 3. 기술 스택 및 아키텍처
- **Frontend**: React, MUI Dialog, Zod/Pydantic 기반 유효성 검사.
- **Backend**: FastAPI Endpoint 신설, UserService 연동.
- **i18n**: 3개 국어(KO, EN, JA) 지원.

## 4. 변경 관리 및 보안
- 인증 없이 접근 가능한 API(`POST /api/v1/accounts/apply`)에 대한 Rate Limiting 고려(추후).
- 백엔드에서 클라이언트가 전달하는 `role`이나 `is_active` 값을 무시하고 상수로 처리함.
