# 계정 신청 기능 기획서 (최종)

## 1. 개요
로그인 페이지에서 일반 사용자가 계정 생성을 신청할 수 있는 기능을 제공합니다. 신청된 계정은 보안상 '비활성화' 상태로 생성되며, 관리자의 승인 후에만 시스템 이용이 가능합니다.

## 2. 기능 요구사항

### 2.1 프론트엔드
- **진입점:** 로그인 페이지(`LoginPage.tsx`) 하단에 '계정 신청' 링크 배치.
- **신청 폼:** `a1.png` 디자인 기반 모달 다이얼로그.
    - 입력 필드: 아이디, 이메일, 이름, 비밀번호, 비밀번호 확인.
    - 필드 제외: 역할(Role), 상태(Status).
- **비밀번호 정책 연동:**
    - `passwordPolicyService`를 통해 정책 로드.
    - 실시간 검증 UI (충족 시 녹색, 미충족 시 빨간색 강조).
- **다국어 지원:** `ko.json`, `en.json`, `ja.json` 반영.

### 2.2 백엔드
- **API 엔드포인트:** `POST /api/v1/auth/apply`
- **데이터 규칙:**
    - `role`: 'user' 고정.
    - `is_active`: `false` 고정.
- **정책 공개:** `GET /api/v1/password-policy` API의 접근 권한을 공개(Public)로 전환.

## 3. 보안
- 백엔드에서 클라이언트 요청 데이터를 재검증하고 강제 값을 적용하여 변조 방지.
- 비로그인 사용자용 정책 조회 API의 보안 취약점 점검.

## 4. 데이터 흐름
1. 사용자가 로그인 페이지 진입 후 "계정 신청" 클릭.
2. 모달에서 정보 입력 및 실시간 정책 체크 확인.
3. "신청" 버튼 클릭 시 이메일 형식 등 최종 검증 후 API 요청.
4. 신청 완료 팝업 표시 및 모달 닫기.
